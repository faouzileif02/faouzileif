# GRITECH WEB DESIGN PRO — Public Skill V2

**Professional web-design skill for Claude Code and other Markdown-based AI agents.**

Create and audit website projects with guidance for premium UX/UI, responsive design, semantic SEO, real dynamic features, security, accessibility, and production-readiness.

### What this repository contains
Only the portable **Skill instructions**. No website source code, generated client project, local Ollama runtime, API keys, `output/`, or execution logs.

### Install in Claude Code
1. Download `SKILL.md` from the `gritech-web-design-pro` folder.
2. Create `~/.claude/skills/gritech-web-design-pro/`.
3. Put the file at `~/.claude/skills/gritech-web-design-pro/SKILL.md`.
4. Open Claude Code in your own web project and ask it to use **GRITECH WEB DESIGN PRO**.

### Sample prompt
> Use GRITECH WEB DESIGN PRO to build a modern responsive website for my business, with credible premium design, local SEO, real contact functionality if the backend is configured, accessibility and a verifiable QA report. Do not deploy without approval.
